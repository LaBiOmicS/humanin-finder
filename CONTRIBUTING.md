# Contributing to HumaninFinder

Thank you for your interest in contributing to HumaninFinder! As a scientific tool, your contributions help advance evolutionary genomics.

## How to Contribute

1.  **Reporting Bugs:** Open an issue on GitHub describing the bug and how to reproduce it.
2.  **Suggesting Features:** We welcome ideas for new models, genetic code support, or improved discovery algorithms.
3.  **Code Contributions:**
    *   Fork the repository.
    *   Create a new branch for your feature.
    *   Add tests for your changes.
    *   Submit a Pull Request.

## Development Setup

We use `pixi` or `conda` for environment management.

```bash
pixi install
pixi run test
```

## Scientific Contributions

If you have new Humanin sequences or validated experimental data, please reach out to improve our AI training datasets.
